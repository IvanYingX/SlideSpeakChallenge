# AI Presentation Analyzer

This is a full-stack AI-powered document analysis system. Upload a PDF, DOCX, or TXT file and receive real-time progress updates, sentiment analysis, and key insights using a simulated AI backend.

## Features

- File upload (PDF, DOCX, TXT)
- Real-time processing updates via WebSocket
- Simulated AI analysis with sentiment, topics, and insights
- Dashboard with Prometheus + Grafana monitoring
- Containerized with Docker Compose

## Prerequisites

- Docker
- Docker Compose

## Setup and Run

```bash
# Clone the repository
git clone https://github.com/SlideSpeak/slidespeak-document-processing-challenge
cd slidespeak-document-processing-challenge

# Build and start all services
docker-compose up --build
```

This will launch the following services:

- FastAPI backend at http://localhost:8000
- React frontend at http://localhost:5173
- Prometheus at http://localhost:9090
- Grafana at http://localhost:3000

## Usage

1. Open http://localhost:3000 in your browser.
2. Upload a supported document (PDF, DOCX, or TXT).
3. Follow real-time progress updates and view the analysis results.
4. Navigate to the dashboard tab for system metrics.

## Metrics and Monitoring

The FastAPI service exposes metrics at `/metrics`. Prometheus scrapes this endpoint and feeds data to Grafana.

### Prometheus Metrics

| Metric                                  | Description                                 |
|-----------------------------------------|---------------------------------------------|
| documents_processed_total               | Number of successfully processed documents  |
| document_processing_errors_total        | Number of failed document processing jobs   |
| document_processing_duration_seconds    | Histogram of processing durations           |

### Accessing the Dashboard

- Prometheus: http://localhost:9090
- Grafana: http://localhost:3000
  Default credentials:
  - Username: `admin`
  - Password: `admin`

To use the dashboard:
1. Login to Grafana.
2. Go to Create → Import.
3. Upload the JSON file named `document_metrics_dashboard.json`.

This dashboard includes:
- Total documents processed
- Processing errors
- Average processing duration (based on Prometheus rate functions)

## Running Tests

```bash
# Run unit and integration tests
docker-compose exec backend pytest
```

## Notes

- Metrics are collected using Prometheus and visualized with Grafana.
- Document IDs are generated by hashing the file content to avoid reprocessing duplicates.
- The AI analysis services are mocked and simulate delays and random failures.

## Future Steps

This project can be further extended and productionized with the following improvements:

### Scalability
- **Move document state to Redis or a database** to support multiple worker processes or horizontal scaling.
- **Use a task queue** like Celery or RQ for distributed, retryable background processing with visibility into queued/completed jobs.

### Observability
- Add **structured logging** and log aggregation (e.g., Loki).
- Integrate **OpenTelemetry** for tracing and metrics across services.
- Expand **Grafana dashboards** with per-chunk stats, error breakdowns, and real-time user activity.

### WebSocket Improvements
- Use **Redis pub/sub** or **FastAPI Broadcast** to manage WebSocket updates across multiple instances.
- Add support for **client reconnects** and historical progress fetch.

### Authentication & Authorization
- Add **user sessions** and scoped document access.
- Secure metrics and admin APIs behind **role-based access control (RBAC)**.

### AI Backend Integration
- Replace mock AI services with real endpoints (e.g., OpenAI, Claude, custom models).
- Add **document chunk embeddings**, **summarization**, or **slide generation**.

### UI Enhancements
- Show detailed progress per chunk.
- Add a **retry queue view** and **document history** panel in the dashboard.
